bad prompt = general prompt which can answer users question without any relation with the situation/Product/work.

So solvig this problem called Prompt Engg.

There are 6 steps of Prompt Engineerg:

1. ROLE
   Mention the role, who are you, domain related, responsibilities

2. TASK
   What work done by the LLM, classification

3. CONSTRAINT
   Give the boundry

4. OUTPUT FORMAT
   what kind of output

5. ZERO SHOT/ONE SHOT/FEW SHOTS
   If you give an example thats called one shot
   EXAMPLE
   For instance if s user complain says he wants a refund then category is Return.

   If you don't give any example that is called ZERO SHOT.

   If you give more than one example that is called FEW SHOTS.

6. FALLBACK
   If the issue is unrelated as mentioned in constraints, then the answer should be OTHER
