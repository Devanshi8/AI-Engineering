AI-Powered Resume Screening System
Project Overview

This is a self-initiated mini project that uses Large Language Models (LLMs) to parse resumes, extract job requirements, and evaluate how well candidate profiles match a given job description.

The system processes resumes in PDF and DOCX formats, converts their contents into structured data, and generates a candidate match score along with evaluation details.

Technologies Used
Programming Language: Python
LLM Integration: Groq API
LLM Model: openai/gpt-oss-120b
Data Validation: Pydantic
Resume Parsing: PyPDF, python-docx
Environment Configuration: python-dotenv
Project Workflow

1. Job Description Processing
   Provide a job description as text input.
   Define a Pydantic schema to represent job requirements, including the role, required skills, preferred skills, experience, education, and responsibilities.
   Use an LLM to extract relevant information from the job description.
   Convert the generated JSON response into a validated job object.
2. Resume Schema Creation
   Create an Experience class to represent employment history, including company, role, duration, description, and skills used.
   Create a Resume class to represent candidate information, including contact details, skills, work experience, education, projects, and certifications.
   Generate a schema from the Pydantic models to guide the LLM in producing structured resume data.
3. Resume Reading and Parsing
   Accept resumes in PDF and DOCX formats.
   Extract text from PDF files using PyPDF and from DOCX files using python-docx.
   Pass the extracted resume text to the LLM for information extraction.
   Convert the generated JSON response into a validated Resume object.
4. Job and Resume Matching
   Pass the structured job description and parsed resume to the LLM for comparison.
   Evaluate matching skills, missing important skills, experience requirements, and overall candidate-job compatibility.
   Return a structured result containing:
   Score: The overall match score generated by LLM on a scale of 0–100.
   Details: Evaluation information explaining the candidate's match with the job requirements.
5. Batch Processing and Candidate Ranking
   Process multiple resumes stored in a designated folder.
   Calculate a match score for each processed resume.
   Sort candidates by their scores in descending order.
   Display the top two and lowest two candidates based on the calculated scores.
   Key Features
   Job description analysis and structured requirement extraction.
   Resume parsing for PDF and DOCX files.
   Structured data extraction using LLMs and Pydantic.
   Candidate-job compatibility evaluation.
   Identification of matching and missing skills.
   Automated batch processing and candidate ranking.
